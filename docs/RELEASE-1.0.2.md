# AetherZip 1.0.2 验证记录

候选版本：1.0.2 / 2026102103，仅 Apple Silicon，macOS 26+。

## 本轮修复

- 批量同名归档在任务实际开始时重新选择输出名称，避免队列内冲突。
- 同名单层目录折叠先完成链接边界校验，再单次发布；保留不相关目录和选择性解压路径。
- 仅提取选中条目时不回收原归档。
- 关闭归档使旧清单失效；退出等待预览和拖拽解压取消、清理完成。
- 拖拽使用原生 TableRow 接口，文件承诺在后台完成，不等待主线程；新增主线程被占用时的交付与退出后拒绝交付回归。
- 拖拽导出保留字符编码，使用精确条目路径，并保留临时文件供接收方复制。
- RAR 现代/传统分卷、ZIP 分卷、7z 数字分卷定位首卷，多选同组去重，缺首卷报错。
- 修复官网缺失更新 feed；旧 EdDSA 私钥未找到，专用钥匙串账号 AetherZip 保存新签名密钥。Developer ID 证书保持一致，需实际验证旧版升级。

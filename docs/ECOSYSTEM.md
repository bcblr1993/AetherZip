# Aether Native 接入约定

当前开发版与现有网站生态采用以下一致方向：

- 产品名称 AetherZip，品牌署名 Aether Native，bundle ID `com.aethernative.AetherZip`。
- SwiftUI / AppKit 原生客户端；本地处理、隐私优先；macOS 26+，arm64-only。
- 蓝紫色主色、轻盈单窗口、系统玻璃材质；网站用于介绍、下载、版本与支持，客户端不嵌入网页壳。
- 本轮未修改 `/Users/chenxu/IdeaProjects/aethernative-site`，未创建公开下载地址、release feed 或授权产品。

后续上线时在网站现有产品目录/版本管理模式内增加 AetherZip，并复用已有支持与隐私页面结构；必须以当时网站源码为准验证字段，不新增一套独立账户或支付系统。

开发版中的官网和支持菜单指向现有 Aether Native 站点。自动更新、公证、产品专页、反馈归属和正式下载需要在发布阶段一起验收。
